# OFFICE RAID

동료를 모아 회사를 키우고 거대한 프로젝트를 공략하는 인재 수집형 오피스 전투 RPG입니다.

작은 회사에서 시작해 다양한 직원을 채용하고, 부서별 능력과 직원 간 협업을 활용해 프로젝트를 완료합니다. 프로젝트에서 얻은 보상으로 직원과 장비를 성장시키고 더 큰 회사로 확장합니다.

## 핵심 구성

- 회사 내부 운영과 성장
- 절차적으로 생성되는 면접 후보자
- 부서별 역할을 활용한 프로젝트 전투
- 직원 간 스킬 연계와 팀 시너지
- 행동으로 충전되는 긴급 지시와 직원별 3지선다 스킬
- 등급별 장비와 프로젝트 보상
- 직원별 3개 장비 슬롯과 장착·교체·해제, 전투 능력치 반영
- 동일 부위·등급 장비 3개를 다음 등급으로 교환하거나 낮은 가격으로 개별 판매하는 장비 중고거래
- 일반 프로젝트 장비 드롭률 40%, 튜토리얼·보스 확정 보상
- 전투 처리량 숫자 이펙트
- 회사 규모별 2·3·4건의 직원 검토 요청형 일일 업무 메일
- 전 직급 직원을 3프로젝트 동안 육성하는 장기 교육과 성과 미니게임
- 여유 인력이 있을 때 발생하는 부서별 지명 출장과 현장 지원 미니게임
- 길게 눌러 옮기고 저장하는 사무실 자리 배치와 확장 후 대표석
- 프로필 격자·상세 패널과 직급·입사·부서·프로젝트 참여순 인사 정렬
- 밤샘·급여 자금 부족·계약 종료에 연동되는 돌발 근로감독과 3가지 대응
- 프로젝트 중 두 직원의 의견 충돌과 해당 전투에만 적용되는 조율 선택
- 성장 목표를 따라 해금되는 경영지원 비서 후보 3인, 영입 이벤트와 화면별 자동 지원
- 조화 팔레트·테두리·업종별 심볼을 조합하는 회사 로고 제작
- 남녀 외형 파츠와 대표 성별 선택, 부서 역할 배지와 실제 적용되는 직원 패시브

## 현재 단계

현재는 설치 없이 실행 가능한 브라우저 프로토타입을 우선 개발합니다. 전투·채용·성장·UI 규칙이 확정되면 Unity 6.3 LTS Android 프로젝트로 한 번에 이식합니다. 반복 수정 단계에서는 Unity와 WebGL 빌드를 매번 갱신하지 않습니다.

**[모바일 웹 미리보기 실행](https://ming87-star.github.io/office-raid/)**

현재 구현된 흐름:

1. 창업 첫날과 첫 프로젝트 의뢰를 보여주는 3장 오프닝
2. 직접 입력하거나 랜덤 생성한 회사 이름과 배경·테두리·업종 심볼 회사 로고 결정
3. 대표 성별을 고르고 이름과 얼굴형·피부·머리·눈·눈썹·코·입·의상·액세서리 커스터마이징
4. 대표를 포함한 초기 직원 3명으로 회사 시작
5. 첫 프로젝트에서 업무량·마감·능력치·행동 순서·긴급 지시를 익히는 전투 튜토리얼
6. 첫 프로젝트 성공 후 면접 기능 해금
7. 절차적으로 생성된 후보자 면접과 채용
8. 속도순 자동 행동과 속도에 비례한 긴급 지시 충전
9. 지원을 먼저 계산하고 스킬별 고유 이펙트를 순차 재생하는 긴급 지시와 `PERFECT WORKFLOW` 연계 연출
10. 프로젝트 완료 후 현금·평판·장비 획득
11. 채용한 직원 중 회사 규모에 따라 3~6명의 프로젝트 참가자 편성
12. 현금과 누적 성과로 소형·중형·대형 사무실 확장
13. 요구사항 변경·긴급회의·예산 삭감·고객 승인 돌발 상황
14. 프로젝트 성공으로 갱신되는 상시채용 공고와 헤드헌팅권 기반 특별채용
15. 회사 운영 상태 자동 저장, 첫 화면 이어하기와 확인 절차가 있는 새 게임 초기화
16. 장비 중고거래 승급·개별 판매·잠금, 일반 프로젝트 드롭률 40%
17. 일반·상성·자동화·긴급 지시별 전투 처리량 숫자 이펙트
18. 업종별 현실형 산수·엑셀·도면 검토 메일과 일일 정확도
19. 성장성과 숙련도에 따라 결과가 달라지는 전 직급 장기 교육과 교육비 관리
20. 최대 프로젝트 인원보다 근무자가 많을 때 발생하는 돌발 지명 출장
21. 교육·출장 2회차에 발생하며 최종 성과를 최대 한 단계 조정하는 순서 선택 미니게임
22. 사무실 확장 후 대표 전용 자리와 근무 구역별 직원 자리 이동
23. 프로젝트 참여 횟수 기록과 좌우 분할형 인사관리 직원 정렬
24. 노무 위험도에 따라 발생하는 돌발 근로감독과 적합·시정 결과
25. 불리한 전투 상황에서 일시 정지되는 프로젝트 전용 구성원 분쟁
26. 이력서형 비서 후보 선택, 영입 안내와 프로젝트·장비·인사·중고거래의 화면별 비서 지원
27. 부서별 프로젝트 역할과 직원 성격 패시브 설명 및 실제 전투 효과

## 실행 방법

1. Unity Hub에서 Unity 6.3 LTS와 Android Build Support를 설치합니다.
2. 이 저장소 폴더를 Unity Hub에서 프로젝트로 추가합니다.
3. `Assets/Scenes/Main.unity`를 엽니다.
4. Play 버튼을 눌러 프로토타입을 실행합니다.

현재 프로토타입 UI와 도트 스프라이트는 코드로 생성되므로 별도의 에셋 설치가 필요하지 않습니다.

화면은 Android 세로 모드를 기준으로 설계했습니다. 기준 해상도는 `360×780`이며 Canvas Scaler, 앵커 레이아웃과 안전 영역 보정으로 `9:16`부터 `9:21`까지 대응합니다. 사무실과 면접에서는 직원이 정면을 바라보고, 전투에서는 같은 외형의 뒷모습으로 위쪽 프로젝트 보스를 바라봅니다. 업무 효과도 직원에서 프로젝트를 향해 아래에서 위로 이동합니다.

자세한 내용은 [게임 기획서](docs/GAME_DESIGN.md)와 [기술 설계서](docs/TECHNICAL_DESIGN.md)를 참고하세요.

웹 미리보기와 선택적 Unity WebGL 자동 배포 설정은 [웹 미리보기 안내](docs/WEBGL_PREVIEW.md)를 참고하세요.

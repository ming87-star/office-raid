# OFFICE RAID 기술 설계서

## 기술 기준

- 엔진: Unity 6.3 LTS
- 우선 플랫폼: Android
- 기본 화면: 세로 화면, 360×780 기준 (`9:19.5`)
- 대응 비율: `9:16`~`9:21`, 노치·펀치홀 안전 영역 적용
- 첫 전투 방식: 3인 배치 후 자동 진행
- 아키텍처: Unity 의존성이 없는 Core와 화면을 담당하는 Runtime 분리

## 프로젝트 구조

```text
Assets/
  Scenes/Main.unity
  Scripts/
    Core/       게임 규칙과 데이터
    Runtime/    Unity Canvas 화면, 도트 그래픽과 입력
  Editor/       Android 세로 방향 프로젝트 설정
  Tests/
    EditMode/   핵심 규칙 테스트
docs/
  GAME_DESIGN.md
  TECHNICAL_DESIGN.md
```

## 현재 구현

### 회사 생성

회사 이름 입력·랜덤 생성 뒤 대표 커스터마이징 화면으로 이동합니다. 대표 이름과 `AppearanceProfile`을 `OfficeRaidGame.CreateCompany`에 전달하고 대표, 영업, 개발 담당자 총 3명으로 시작합니다. 초기 보유 현금, 직원 정원과 프로젝트 참가 인원도 이 메서드에서 관리합니다.

### 면접과 외형 조합

`CandidateGenerator`는 이름, 부서, 숙련도, 능력치, 성격, 급여와 외형 파츠 인덱스를 생성합니다. `PixelArtFactory`는 얼굴 8종, 피부 6종, 머리 16종, 눈 10종, 눈썹 8종, 코 8종, 입 10종, 액세서리 9종, 의상 12종을 24×24 도트 초상화로 조립합니다. 모든 파츠 값이 스프라이트 캐시 키에 포함되어 서로 다른 조합이 같은 이미지로 재사용되지 않습니다. `Portrait`은 사무실·면접용 정면, `PortraitBack`은 프로젝트 전투용 뒷모습을 생성하며 피부·머리·의상 파츠를 공유합니다.

숙련도 기본 확률:

- 신입 60%
- 경력자 25%
- 전문가 10%
- 에이스 4%
- 업계 전설 1%

### 프로젝트 전투

`BattleSimulator`는 Unity 프레임워크와 분리된 순수 C# 규칙입니다. 직원은 속도순으로 행동하고, 부서 능력과 추천 부서 보너스를 사용해 프로젝트의 남은 업무량을 감소시킵니다.

현재 핵심 연계:

1. 영업이 요구사항을 정리합니다.
2. PM이 팀의 모멘텀을 올립니다.
3. 개발이 정리된 요구사항과 모멘텀을 이용해 추가 업무 피해를 줍니다.

2일차부터 일정 확률로 프로젝트 돌발 상황이 발생합니다. 요구사항 변경은 업무량을 되돌리고 영업의 요구사항 정리를 초기화하며, 긴급회의는 당일 효율을 낮추고, 예산 삭감은 2일 동안 처리량을 감소시킵니다. 고객의 빠른 승인은 2일 동안 처리량과 모멘텀을 높입니다. `BattleSimulator`가 현재 상태 이름과 남은 기간을 제공하므로 Unity와 웹 화면에서 같은 규칙을 표시할 수 있습니다.

회사는 `SelectedProjectTeamIds`에 프로젝트 참가자 3명을 순서대로 저장합니다. 전투 시 직원 목록의 앞 3명을 임의로 쓰지 않고 저장된 팀을 불러오며, 퇴사자 ID나 잘못된 인원수는 Core 규칙에서 거부합니다.

전투 화면은 프로젝트 보스를 위쪽, 뒷모습의 직원을 아래쪽에 배치합니다. 영업의 요구사항 정리와 개발의 코드 블록은 아래에서 위로 이동하고, PM의 일정표는 팀 앞에 방어막으로 표시됩니다. 모든 도트 스프라이트는 `PixelArtFactory`가 작은 런타임 텍스처로 생성하며 `FilterMode.Point`를 사용합니다. 브라우저 미리보기는 Unity의 좌하단 원점과 HTML Canvas의 좌상단 원점 차이를 `rect` 변환 함수에서 보정해 두 버전의 상하 방향을 일치시킵니다.

### 세로 화면 대응

- `CanvasScaler` 기준 해상도: 360×780
- 모든 주요 화면: 비율 앵커 기반 배치
- `SafeAreaFitter`: `Screen.safeArea` 변경을 감지해 노치와 시스템 표시 영역 회피
- Android 방향: Portrait 고정, 가로 자동 회전 비활성화
- 긴 화면의 추가 공간은 전투장과 카드 사이 여백으로 흡수

### 보상

프로젝트 성공 시 현금, 평판과 무작위 장비를 획득합니다. 실패 시 직원이나 장비는 잃지 않고 현금 일부만 차감됩니다.

## 테스트

Unity Test Runner의 EditMode에서 다음 항목을 검증합니다.

- 회사 생성 시 직원 3명 배치

- 면접 후보의 외형 파츠 범위
- 초기 팀의 프로젝트 완료 가능 여부
- 강제 돌발 상황 발생과 임시 상태 적용
- 프로젝트 성공 보상 중복 방지와 지급 결과

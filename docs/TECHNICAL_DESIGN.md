# OFFICE RAID 기술 설계서

## 기술 기준

- 엔진: Unity 6.3 LTS
- 우선 플랫폼: Android
- 기본 화면: 16:9 가로 화면
- 첫 전투 방식: 3인 배치 후 자동 진행
- 아키텍처: Unity 의존성이 없는 Core와 화면을 담당하는 Runtime 분리

## 프로젝트 구조

```text
Assets/
  Scenes/Main.unity
  Scripts/
    Core/       게임 규칙과 데이터
    Runtime/    Unity 화면과 입력
  Tests/
    EditMode/   핵심 규칙 테스트
docs/
  GAME_DESIGN.md
  TECHNICAL_DESIGN.md
```

## 현재 구현

### 회사 생성

회사 이름을 입력하고 대표, 영업, 개발 담당자 총 3명으로 시작합니다. 초기 보유 현금, 직원 정원과 프로젝트 참가 인원은 `OfficeRaidGame.CreateCompany`에서 관리합니다.

### 면접과 외형 조합

`CandidateGenerator`는 이름, 부서, 숙련도, 능력치, 성격, 급여와 외형 파츠 인덱스를 생성합니다. 외형은 얼굴, 피부, 머리, 눈, 눈썹, 코, 입, 액세서리와 의상으로 분리되어 향후 투명 PNG 파츠를 연결할 수 있습니다.

숙련도 기본 확률:

- 신입 60%
- 경력자 25%
- 전문가 10%
- 에이스 4%
- 업계 전설 1%

### 프로젝트 전투

`BattleSimulator`는 Unity 프레임워크와 분리된 순수 C# 규칙입니다. 직원은 속도순으로 행동하고, 부서 능력과 추천 부서 보너스를 사용해 프로젝트의 남은 업무량을 감소시킵니다.

현재 핵심 연계:

1. 영업이 요구사항을 정리합니다.
2. PM이 팀의 모멘텀을 올립니다.
3. 개발이 정리된 요구사항과 모멘텀을 이용해 추가 업무 피해를 줍니다.

### 보상

프로젝트 성공 시 현금, 평판과 무작위 장비를 획득합니다. 실패 시 직원이나 장비는 잃지 않고 현금 일부만 차감됩니다.

## 테스트

Unity Test Runner의 EditMode에서 다음 항목을 검증합니다.

- 회사 생성 시 직원 3명 배치
- 면접 후보의 외형 파츠 범위
- 초기 팀의 프로젝트 완료 가능 여부
- 프로젝트 성공 보상 중복 방지와 지급 결과
